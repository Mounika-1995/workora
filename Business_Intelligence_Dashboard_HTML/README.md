# Business Intelligence Dashboard — Browser Version

No Python, Node.js, or Streamlit is required to run this version.

## Run locally
Double-click `index.html` or open it in Chrome/Edge. An internet connection is needed for the Plotly chart library.

## Publish for a public submission URL
Upload `index.html` to a GitHub repository and enable GitHub Pages. The resulting `github.io` URL can be submitted as the public dashboard URL.

## Dashboard
- Executive KPI cards
- Date range, region, traffic-source filters
- Conversion funnel
- Traffic-source comparison
- Churn by contract
- Checkout A/B conversion
- Regional demand vs competition
- Session duration by region
- Regional opportunity signal
